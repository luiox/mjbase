共享方法体 AST
===============

状态：部分落地（共享节点、JVM 提升与常量写回、DEX 提升与调用点提取）。

``mjbase::ast``\ 为 JVM 和 DEX 方法体定义同一套节点。二进制格式的解析、保真表示和
编码分别由 libjbc 与 libdex 承担。适配器解析常量池或 DEX ID 表，在 AST 中用
``MemberKey``\ 表达字段和方法引用。调用者为两种格式传入同一个 ``KeyPool``\ ，即可
按类内部名、成员名、描述符比较身份。AST 持有节点及字面量，符号文本随池存活。

节点与求值顺序
--------------

``MethodBody``\ 记录接收者、按描述符顺序排列的参数变量，以及含入口的基本块表。
``LocalId``\ 表示可变变量，赋值结果可沿控制流传递。``ValueId``\ 表示当前块内较早
的 ``Let``\ 语句。块内按语句顺序执行，每条 ``Let``\ 求值一次，因此多处使用同一
结果时会复用该次求值。字段读取、调用和局部变量读取都遵循这个顺序。例如，在赋值前
取得的局部值在赋值后仍能引用。

表达式覆盖常量、局部变量读取、整数二元运算、字段读取及调用。语句可赋值、写字段，
也可调用并忽略返回值。字段和调用节点用可选接收者表达实例访问和静态访问。字符串按
UTF-16 码元保存，包括 NUL 和未配对代理码元。DEX 32 位常量可保留为 ``Bits32``\ ，
由使用它的操作解释为整数、浮点数或空引用。

基本块以跳转、条件分支、返回或抛出终结。目标是 ``BlockId``\ ，因此循环和汇合直接
表达为图上的边。当前适配器要求整个方法属于支持范围，遇到超出范围的指令或控制流会
返回错误，例如 switch 或动态调用。位置可用时，错误会带上 JVM 指令
序号或 DEX code unit 地址。适配器在提升过程中执行结构检查，完整验证仍由对应的
字节码工具承担。

``directCalls``\ 遍历任何一种适配器的产物，按块及语句顺序返回符号目标、分派方式和
调用点。它包含结果被丢弃的调用，也包含不可达块里的调用。层次分派、可达过滤和跨类
汇总由调用者在符号调用点之上执行。

.. _semantic-ast-jvm:

JVM 读取与编辑
--------------

``liftJvmMethod``\ 从 libjbc 会话取得或升格方法体，复用现有 CFG 划分基本块。适配器
在每个块内把操作数栈转换成对 ``ValueId``\ 的引用。普通出边携带同一组栈值，
接收块用有类型的块参数表示从各条入边取得的值。栈复制和换位调整同一组值引用，
因此复制调用结果时只产生一次调用节点。

``rewriteJvmLiterals``\ 接收 classfile 字节并按方法名和描述符定位方法。回调读取原始
AST 和符号池，按节点选择替换为同类型的整数或字符串。回调只访问有对应载入指令的
常量，例如分支比较隐含的零是提升时补入的表达式。适配器用独立会话解析并提交整次
修改，由 libjbc 驻留常量、重算指令布局并写出 classfile。回调保留全部常量时返回
原始字节。读取、提升、编辑或写回失败时返回错误，调用者可保留原始输入。

.. _semantic-ast-dex:

DEX 读取与分析
--------------

用 ``xmake f --with_dex=y``\ 启用 ``mjbase_dex``\ ，该目标依赖 ``mjbase``\ 与
``libdex``\ 。``liftDexMethod``\ 接收已读入的 ``DexFile``\ 和来自其类数据的
``EncodedMethod``\ 。它将寄存器映射为 ``LocalId``\ ，按描述符绑定参数，规约字段
访问的编码变体，并将同块内相邻的调用及 ``move-result``\ 表达为一次求值和一次赋值。
DEX 侧当前提供读取到 AST 的入口，分析可直接消费 ``MethodBody``\ 和 ``directCalls``\ 。
对于异常区间，适配器把处理器入口的 ``move-exception``\ 建模为从捕获对象赋值。

异常边
------

异常表把受保护区间分成基本块。块按异常表顺序记录处理器，异常边给处理器提供
捕获对象，普通局部值沿异常发生点传递。一次抛出可能发生在块内不同位置，整数
传播只在没有异常边的方法中启用。支配和可达分析可以直接把处理器视为后继。
优化与图分析的当前接线见 :ref:`ast-pass-validation`。

后续扩展
--------

后续可继续扩充 switch、对象构造、数组和动态调用。对写回，优先将具有明确来源
且可验证的节点修改映射回原格式。新增控制流或调整局部变量布局的变换由后端实现
降级与验证。
