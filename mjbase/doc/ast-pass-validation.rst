共享 AST 的优化与分析
=====================

状态：部分落地（JVM 常量传播与折叠、条件改写、方法堆效应和图分析已接入）。

块内常量传播
------------

``analyzeBlockConstants``\ 从每个基本块入口的未知局部状态开始，按语句顺序计算常量。
``Let``\ 保存该点的求值结果，后续对同一局部的赋值只更新新的读取。整数二元运算使用
Java 的定宽回绕和移位规则，除数为零时该表达式的结果未知。调用结果和字段读取也按
未知处理，已经得到的局部常量继续有效。

局部读取携带槽值类型。JVM 的整数零与空引用分别追踪。DEX 的 32 位立即数保留原始
位模式，在确认整数或引用用法后解释。双槽写入使目的槽与覆盖槽的窄值事实失效。

``LocalConstantPropagation``\ 对可提升的 JVM 方法使用这些事实，将有已知整数值或空
引用的读取原位改写。JVM 适配器提供语句的源指令句柄，改写时保留句柄和来源 PC，
再由现有方法写回流程处理布局和元数据。块入口标签可沿用，遇到块内标签边界或提升
失败时调用原有指令传播路径。该入口沿用块内传播的范围。

跨块常量传播与条件改写
----------------------

``analyzeIntFlow``\ 为局部变量和块参数计算可达的入口事实。合流只保留所有到达路径
都同意的整数值，循环通过工作列表求不动点。分支事实在收敛后计算，因此已知分支
方向仍保留在合流中，不参与提前裁剪。分析遇到异常边或超出工作预算时回退。

DEX 的原始 32 位常量与整数运算结果按位相同时，合流保留原始位模式，直到整数
读取或运算确认用法。局部变量和块参数采用相同规则。

``ConstantPropagator``\ 用这些事实替换 JVM 的整数局部读取，原 def-use 路径继续
处理非整数及超出 AST 提升范围的方法。``ConsJumpOptimizer``\ 在相邻窗口折叠之后
再检查剩余条件。对已知恒假的整数分支，后端只替换条件指令本身，用 ``POP``\ 或
``POP2``\ 保持栈消费，原操作数求值和顺序后继均得到保留。通用恒真改写需要验证
新增不可达入口的帧。

常量折叠与写回
--------------

``ConstantFolder``\ 在常量链扫描后使用跨块整数事实，折叠由已知局部读取或常量
装载组成的相邻二元表达式。一次分析后沿定义顺序更新结果的源指令锚点，连续表达式
可在同一遍历中完成折叠。调用与其他求值的执行顺序保持。

折叠保留链首的指令句柄和来源 PC。内部标签、行号、局部范围、栈帧及其他已识别
Code 元数据所引用的位置阻止对应窗口删除，未知或无法解析的属性使本方法跳过
结构折叠。常量池容量检查允许复用已有常量，无法容纳新值时保留原指令。

回归覆盖常量池满时的 IINC 传播、元数据写回、长表达式链、跨块合流和除零行为。
JVM 执行对照同时检查优化后的返回值与可观察调用。

可达性、支配与支配边界
----------------------

``ast::ControlFlowGraph``\ 消费 AST 普通边和异常边。原 ``asm_cfg``\ 的遍历和支配树
通过适配器调用同一套计算，供 RegionView 与 outline 使用。不可达指令清理可先用
AST 可达性识别没有死块的方法，实际删除仍须通过原有帧分析和编辑检查。

方法堆效应与调用边
------------------

``summarizeEffects``\ 扫描方法各块，提取局部堆效应和符号调用目标。字段读取为只读，
字段写入和显式抛出为有副作用。调用边保持程序顺序，包括不可达块及重复调用。
``MethodEffectModel``\ 在提升成功时使用这些结果，继续按现有调用关系传播效果。
提升失败时沿用原有字节码扫描。常量返回形状仍由现有扫描识别。

这组摘要的契约是堆效应与调用关系。删除或重排指令还需要证明异常行为、类初始化、
空引用检查和同步语义，并把这些约束带入写回检查。

JVM 与 DEX 的等价测试
---------------------

JASM 与 smali 样例使用同一组共享分析。块内例对照常量、只读堆效应和符号调用目标。
跨块例对照合流值、直接支配者和支配边界。JVM pass 测试还使用真实 JVM 验证改写
保持行为。

后续迁移的语义条件
------------------

- 需要单次定义的分析可在块参数和支配边界的基础上派生 SSA。分析沿异常边传播
  局部值时需要按可能抛出的语句分开处理各个入口状态。
- 移动或删除求值的变换还需明确每一节点可能抛出的异常和可观察效应。
- 新建控制流或重排局部布局需要对应后端降级并验证。宽数值、浮点和更多操作的支持
  随迁移消费点扩展。

共享方法体及其当前提升范围见 :ref:`semantic-ast`。
