# IllegalClassFileCleaner golden 对拍声明清单（默认零差异；当前无声明条目）。
# 格式：<语料名> <类目码>；'#' 后为注释；行首段对应
# mjbase/test_resource/pass_golden/corpus/jcf/<语料名>.class。
#
# 语料事实（旧栈侧提取器 probeOldTransform 的证据面，见
# mbase/unittest/pass/golden/pass_golden_extract_test.cpp）：
#   - 结构性垃圾（越界/空区间异常表条目，hb_junk_exc）在 jcf 语料道的读取期
#     即被旧栈 ClassFileReader 校验族吸收（3 条入库 1 条），语料不含此类条目，
#     golden 与 mjbase copy-through 输出逐字节一致；
#   - 非法描述符成员（hb_bad_desc）由 transform 规则 1 触发，两栈同规则整条
#     剔除，逐字节一致；
#   - 未知属性（hb_unknown_attr）经 jclassfile DefaultAttribute 与 libjbc Raw
#     两侧保真，逐字节一致。
# 旧栈其余清洗规则（LVT/LNT 修剪、BSM 压缩、RETURN 桩替换等）已于 F 线清洗批
# 经 libjclassfile 前置级随 IllegalStrippingTransformer 全量接入；语料道规范形
# 使这些规则无触发面，仍无类目可声明。
