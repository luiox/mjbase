# 调用链与调用树视图（CallGraph Views）

## 定位

`CallGraph` 的集合/边级查询回答不了「根到叶有哪些调用路径」「展开成可折叠调用树长什么样」。本视图层补齐这两类查询，是调用图的**只读投影**：不新增分析事实、不解析虚分派、不改变既有查询语义。

## 链与树的取舍

| | 链枚举 | 调用树 |
|---|---|---|
| 环 | 跳过，不产出含重复方法的链 | 保留 cycle 叶节点，UI 可画回边 |
| 重入 | 不同路径各一条链 | 每次出现一个节点，`methodId` 去重 |
| 输出 | 根到叶序列流，按需拉取 | 一次性先序数组，有 `maxNodes` 上限 |
| 适用 | 报告/规则解释 | UI/人工审计 |

- 链的边按去重后的被调方法计（方法序列，非调用点序列）；需要逐调用点事实回 `outgoingSitesOf`。
- 游标惰性：只持当前 DFS 路径，内存与深度成正比。路径总数是指数级是问题本身的性质，消费方按需拉取、随时停止。
- 两者都不修改图，可对同一图并发创建只读视图；游标与树都借用图，图销毁后不得使用。

## 非目标

不解析虚/接口分派（层次感知路径枚举应在 `ResolvedCallGraph` 上另做）；不做最短路径、权重、支配关系；不做反向枚举（反向沿用 `callersOf`）。
