# 字符串/常量流分析（string_flow）

## 定位

为下游 pass 提供两类事实：哪些字符串常量只进不逃逸（folding 用）、哪段代码把哪段输入解成了什么（解密内联用）。分析只产出事实，不改写方法体。

流格只记值的来源令牌，不携带字符串内容；控制流、槽迁移与合并全部交给 `jbc::analysis::DomainEngine`。不同来源在汇合点合并为 Top，循环与多路径不会留下伪造的确定值。

## 事实语义

- `StringFlowSource.value` 是 modified UTF-8 字节，可直接交给 `ConstantPool::addUtf8`；空串与不可求值都表现为空视图，用 `complete` 区分，消费方不得只看 value。
- 逃逸判定决定负向结论可信度：返回值、字段与数组存储、未知调用算逃逸；中性搬运不算。结论必须叠加 `escaped` 与扫描范围假设。

## 边界

明确不做：跨方法/跨字段的字符串流（参数与字段加载一律未知）；依赖运行时 charset 的字节解码与反射等外部输入；多次循环迭代累积的数组内容；非字符串调用返回值的建模。

求值在数据流收敛后按令牌递归回溯，带活动集、记忆化与预算，遇环或超预算返回不可求值——不猜测内容。数据流失败时 `summary().ok=false`，事实列表为空（fail-closed）。
