共享 AST 的优化与分析
=====================

状态：部分落地（JVM 局部常量传播与方法堆效应扫描已接入，JVM 和 DEX 共用事实计算）。

块内常量传播
------------

``analyzeBlockConstants``\ 从每个基本块入口的未知局部状态开始，按语句顺序计算常量。
``Let``\ 保存该点的求值结果，后续对同一局部的赋值只更新新的读取。整数二元运算使用
Java 的定宽回绕和移位规则，除数为零时该表达式的结果未知。调用结果和字段读取也按
未知处理，已经得到的局部常量继续有效。

局部读取携带槽值类型。JVM 的整数零与空引用分别追踪。DEX 的 32 位立即数保留原始
位模式，在确认整数或引用用法后解释。双槽写入使目的槽与覆盖槽的窄值事实失效。

``LocalConstantPropagation``\ 对可提升的 JVM 方法使用这些事实，将有已知整数值或空
引用的读取原位改写。JVM 适配器提供语句的源指令句柄，改写时保留句柄和来源 PC，
再由现有方法写回流程处理布局和元数据。块入口标签可沿用，遇到块内标签边界或提升
失败时调用原有指令传播路径，保留该路径的传播范围。共享事实按块隔离，跨块局部值
传递需要合流分析。

方法堆效应与调用边
------------------

``summarizeEffects``\ 扫描方法各块，提取局部堆效应和符号调用目标。字段读取为只读，
字段写入和显式抛出为有副作用。调用边保持程序顺序，包括不可达块及重复调用。
``MethodEffectModel``\ 在提升成功时使用这些结果，继续按现有调用关系传播效果。
提升失败时沿用原有字节码扫描。常量返回形状仍由现有扫描识别。

这组摘要的契约是堆效应与调用关系。删除或重排指令还需要证明异常行为、类初始化、
空引用检查和同步语义，并把这些约束带入写回检查。

JVM 与 DEX 的等价测试
---------------------

JASM 与 smali 样例使用同一组共享分析，得到整数 ``12``\ 、只读堆效应和同一符号调用
目标。JVM pass 测试进一步检查已知读取被改写为常量，DEX 用例验证事实提取。

后续迁移的语义条件
------------------

- 跨块传播首先需要为 JVM 操作数栈传值建模，并对可变局部求入口合流状态。需要
  单次定义的分析可从该 CFG 派生 SSA。
- 处理异常和 switch 要求完整的后继边，包含受保护范围及其处理器。移动求值或删除
  求值的变换还需明确每一节点可能抛出的异常和可观察效应。
- 新建控制流或重排局部布局需要对应后端降级并验证。宽数值、浮点和更多操作的支持
  随迁移消费点扩展。

共享方法体及其当前提升范围见 :ref:`semantic-ast`。
